사이트 이름은 로고와 일치하는 **특허법인 본**으로 통일했습니다. 검색 결과의 실제 사이트 이름과 스니펫은 검색엔진이 결정하며 코드만으로 확정할 수 없습니다.

## 코드 적용과 별도 확인 항목

코드에서 적용한 항목: 시맨틱 `main`·H1 구조, 초기 HTML 본문, 고유 메타 정보, canonical, 내부 링크, 이미지 alt, WebP, Open Graph, JSON-LD, 예약 칼럼 공개 제어, 기존 robots/sitemap 연결.

별도 확인이 필요한 항목: Google Search Console과 네이버 서치어드바이저의 최신 색인 상태·크롤링 오류·sitemap 처리 결과, 실제 검색 결과의 노출 상태, 실제 사용자 데이터 기반 속도 지표. 검색 순위 상승이나 색인 완료는 코드 배포만으로 확인되지 않습니다.

참고: [Google의 JavaScript SEO 가이드](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics), [Google 사이트 이름 가이드](https://developers.google.com/search/docs/appearance/site-names), [Google canonical 가이드](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls), [네이버 SEO 가이드](https://searchadvisor.naver.com/guide/seo-help).

## 확인한 항목

- HTML 검사: 공개 대상 페이지 13개의 `main`과 H1이 각 1개, canonical이 각 1개이며 이미지에 `alt` 속성이 있음.
- 자동 테스트: Python 16개, Cloudflare 공개 제어 Worker 3개 통과.
- 브라우저 검사: Edge에서 주요 6페이지와 PCT 칼럼의 렌더링·헤더 링크·제목·canonical 확인. 상담 페이지에서 해외 특허 선택 시 해외 입력란만 보이는지 확인. PC 및 모바일 화면을 확인하고 메인 제목의 줄바꿈을 기존 구성에 맞게 조정.
- 히어로·중간 이미지 11개의 파일 크기 합계: PNG 약 20.4 MB에서 WebP 약 0.92 MB로 감소. 화면에는 동일한 원본 구도를 사용.
- 공개 사이트의 새 HTML 반영과 검색엔진 관리자 화면의 처리 상태는 배포 후 별도로 확인.
