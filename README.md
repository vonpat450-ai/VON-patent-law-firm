# 특허법인 본 홈페이지

정적 HTML/CSS/JavaScript 사이트입니다. 공개할 파일은 `dist/`에 있습니다.

## Cloudflare Pages 연결

GitHub 저장소의 `main` 브랜치를 Cloudflare Pages에 연결합니다. Framework preset은 `None`, Build command는 비워 두고, Build output directory는 `dist`로 설정합니다. 배포 후 무료 `*.pages.dev` 주소를 사용할 수 있습니다. 이 사이트에는 npm 빌드가 필요하지 않습니다.

## 상담 이메일

상담 폼은 [FormSubmit](https://formsubmit.co/documentation)에 POST로 전송합니다. 첫 신청 후 `vonpat450@gmail.com`에 도착하는 인증 메일의 링크를 한 번 승인해야 실제 상담 메일이 전달됩니다. 배포 후 테스트 신청을 보내고 수신 여부를 확인하세요.

## 보류 중인 작업

특허 칼럼의 AI 자동 작성은 회사에서 칼럼 양식을 제공한 뒤 설계합니다. 특허정보검색 화면은 현재 예시 데이터이며 실제 특허 검색 API와 연결되어 있지 않습니다.
